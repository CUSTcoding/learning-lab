## 🐍 Por que estou aprendendo Python?

Python foi uma das linguagens que fez parte do início da minha jornada na programação.

Foi com Python que comecei a explorar programação e também a desenvolver alguns dos meus primeiros projetos e estudos, incluindo experiências relacionadas a **Bitcoin**.

Atualmente, continuo estudando outras linguagens, como Rust e Go . Porém, Python continua sendo uma linguagem importante para minha formação, principalmente na area de Automação e Visão computacional tambem pela sua simplicidade e pela facilidade de transformar ideias em código.

Este repositório, entretanto, não tem como objetivo estudar Python por completo.

O foco aqui é **construir fundamentos sólidos de programação e lógica utilizando Python como ferramenta de aprendizagem**.

Quero aprender a pensar como programador antes de me preocupar com frameworks, bibliotecas ou tecnologias específicas.

---

## Lógica de programação

Antes de aprender tecnologias avançadas, é importante compreender como resolver problemas utilizando código.

Neste estudo, quero desenvolver habilidades como:

* Entender problemas;
* Dividir problemas em partes menores;
* Criar algoritmos;
* Trabalhar com variáveis;
* Tomar decisões;
* Repetir operações;
* Trabalhar com dados;
* Criar funções;
* Organizar soluções;
* Desenvolver raciocínio lógico.

A ideia é transformar:

```text
Problema
   ↓
Análise
   ↓
Algoritmo
   ↓
Código
   ↓
Resultado
```

Python será a ferramenta utilizada para colocar esses conceitos em prática.
