# Rust Fundamentals

> Estudos dos fundamentos da linguagem Rust, com foco em programação segura, eficiente e no desenvolvimento de uma base sólida para sistemas e problemas complexos de engenharia de software.

---

## 🦀 Por que estou aprendendo Rust?

Rust se tornou minha **linguagem favorita**.

Ainda não sei explicar completamente o motivo, mas desde que comecei a conhecê-la, ela chamou muito a minha atenção.

Parte disso vem da forma como Rust tenta combinar características que normalmente exigem compromissos entre si:

* Performance;
* Segurança de memória;
* Controle sobre recursos;
* Concorrência segura;
* Abstrações sem perder desempenho;
* Ferramentas modernas para desenvolvimento.

Rust também despertou meu interesse por aparecer em projetos relacionados a **Bitcoin, criptografia, blockchain, infraestrutura e sistemas distribuidos**.

Isso combina diretamente com algumas das áreas que quero explorar na minha jornada como desenvolvedor.

Quero compreender não apenas como escrever programas que funcionam, mas também como construir software que seja **seguro, eficiente, previsível e confiável**.

---

## ⚙️ Rust e engenharia de software

Um dos motivos que mais me interessa em Rust é a possibilidade de utilizá-la para resolver problemas que exigem maior atenção a:

* Memória;
* Performance;
* Concorrência;
* Segurança;
* Gerenciamento de recursos;
* Sistemas distribuídos;
* Infraestrutura;
* Software de baixo nível.

Quero utilizar Rust para sair gradualmente de problemas simples e começar a enfrentar problemas que exigem mais raciocínio de **engenharia de software**.

## ₿ Rust e Bitcoin

Meu interesse por Rust também está relacionado ao **Bitcoin e ao ecossistema de criptografia e blockchain**.

Bitcoin foi uma das áreas que me levou a querer entender melhor conceitos como:

* Criptografia;
* Hashing;
* Assinaturas digitais;
* Chaves públicas e privadas;
* Elliptic Curve Cryptography;
* Transações;
* Wallets;
* Redes P2P;
* Consenso;
* Sistemas distribuídos.

Rust me chamou atenção justamente por aparecer em diferentes projetos e ferramentas desse ecossistema.

Meu objetivo não é apenas utilizar bibliotecas prontas.

Quero entender os fundamentos necessários para, no futuro, conseguir construir minhas próprias ferramentas e compreender melhor como sistemas desse tipo funcionam internamente.
