# Go Fundamentals

> Estudos dos fundamentos da linguagem Go, com foco em programação concorrente, performance, desenvolvimento de software moderno e construção de uma base para trabalhar com Cloud e DevSecOps.

---

## 🐹 Por que estou aprendendo Go?

Go é uma das linguagens que escolhi estudar por causa de algumas características que considero importantes para minha formação como desenvolvedor.

Uma das principais é o seu suporte à **concorrência**, especialmente através de *goroutines* e *channels*.

Quero compreender como criar programas capazes de executar várias tarefas de forma concorrente e como esse modelo pode ser utilizado para construir aplicações eficientes e escaláveis.

Outro motivo é que vejo Go como uma alternativa interessante para alguns cenários em que tradicionalmente utilizaria **Java**.

Não significa que Go substitua Java em todos os casos, mas quero conhecer uma linguagem moderna, simples e eficiente que possa ser utilizada em diferentes tipos de sistemas, especialmente backend e infraestrutura.

Go também me interessa pela sua velocidade, compilação para binários e simplicidade de distribuição.

---

## ☁️ Go e Cloud

Outro fator importante para eu estudar Go é sua forte presença no desenvolvimento de **infraestrutura e sistemas Cloud**.

Como tenho interesse em **DevSecOps**, considero importante conhecer uma linguagem utilizada para construir ferramentas, serviços e componentes de infraestrutura.

---

## Go e DevSecOps

Como tenho interesse em **DevSecOps**, aprender Go também faz parte da minha preparação para trabalhar com desenvolvimento, infraestrutura e segurança de forma integrada.

Go será, portanto, uma das linguagens que quero utilizar para aproximar meus conhecimentos de **desenvolvimento de software, Cloud, DevOps e segurança**.

O objetivo é entender não apenas como utilizar essas ferramentas, mas também **quando a concorrência realmente é necessária e quais problemas ela pode introduzir**.
